# OpenWiki Server 命令行测试与调用指南

> 覆盖五类接口：**HTTP（curl） / CLI / gRPC / MCP / Celery(jobs)**；
> 全部命令已用仓库内真实文档（`docs/进展.md`、`docs/解决方案.md`、`README.md`）实测通过。
> 一键演练：`bash scripts/wiki_api_drill.sh`（隔离数据目录 `/tmp/ow-live`，端口 18021，离线规则模式）。

统一响应 envelope：`{"traceId","errCode","errMsg","data"}`；`errCode=0` 成功，
`200001` 参数非法 / `200404` 不存在 / `200409` 冲突 / `200500` 内部错误。

## 0. 前置与启动

```bash
cd /home/sharkyai/openwiki-server
# 安装入口（复用已有 venv）
pip install -e . --no-build-isolation

# 方式 A：本地起 HTTP 服务（离线规则模式，确定性、无需 LLM/网络）
export OPENWIKI_SERVER_DATA_DIR=/tmp/ow-live
export OPENWIKI_SERVER_OPENWIKI=0          # 0=离线规则切页；默认 1=OpenWiki 内核(LLM)
export OPENWIKI_SERVER_HTTP_PORT=18011
openwiki-server serve http                 # 等价：uvicorn openwiki_engine.interfaces.http_app:create_app --factory --port 18011

# 方式 B：Docker 单镜像栈（HAProxy 入口）
bash scripts/build_docker.sh && docker compose up -d
# 冒烟断言：bash scripts/docker_smoke.sh
```

定义公共变量：

```bash
BASE=http://127.0.0.1:18011
# WID 取 create 返回值 data.wikiId
```

## 1. 存活/就绪探针

```bash
curl -sS "$BASE/health"                     # {"status":"ok","service":"openwiki-server"}
curl -sS "$BASE/ready"                      # {"status":"ready"}
```

## 2. Wiki CRUD

```bash
# 创建（kbId 必填；wikiId = "wiki_" + sha1(kbId)[:12]）
curl -sS -X POST "$BASE/api/v1/wiki/wikis" -H 'Content-Type: application/json' -d '{
  "kbId":"kb_live_demo","name":"OpenWiki 服务能力演示","tenantId":"t1","ownerId":"o1",
  "wikiConfig":{"granularity":"heading","extractFields":["负责人","状态"]}}'
WID=wiki_241699365ac0   # 以实际返回为准

# 列表（tenantId/ownerId 过滤）/ 详情 / 删除
curl -sS "$BASE/api/v1/wiki/wikis?tenantId=t1"
curl -sS "$BASE/api/v1/wiki/wikis/$WID"
curl -sS -X DELETE "$BASE/api/v1/wiki/wikis/$WID"
```

## 3. 建页（build，真实文档）

`granularity=heading` 时按标题切页（根页 + 每级标题一页）。实测 `docs/进展.md` → 11 页、
`docs/解决方案.md` → 9 页。

```bash
# 把真实 markdown 文件装进 payload（避免手工转义）
DOC_JSON=$(python -c "import json;print(json.dumps({
  'docId':'doc_progress','title':'任务进展记录','tags':['运维','进展'],
  'markdown':open('docs/进展.md',encoding='utf-8').read()}))")

curl -sS -X POST "$BASE/api/v1/wiki/wikis/$WID/build" \
  -H 'Content-Type: application/json' -d "$DOC_JSON"
# → data: {"mode":"rule","total":11,"deprecated":0,"pages":[...]}

# 第二份真实文档（不同标题/tags）
DOC_JSON2=$(python -c "import json;print(json.dumps({
  'docId':'doc_design','title':'OpenWiki Server 解决方案','tags':['方案','架构'],
  'markdown':open('docs/解决方案.md',encoding='utf-8').read()}))")
curl -sS -X POST "$BASE/api/v1/wiki/wikis/$WID/build" -H 'Content-Type: application/json' -d "$DOC_JSON2"
```

## 4. 增量加工：merge / deprecate-doc

```bash
# merge：显式页面记录合并（title 归一化出稳定 pageId）
curl -sS -X POST "$BASE/api/v1/wiki/wikis/$WID/merge" -H 'Content-Type: application/json' -d '{
  "docId":"doc_merge",
  "pages":[{"title":"开放平台统一认证","tags":["认证","设计"],
            "fields":{"负责人":"安全组"},"markdown":"# 开放平台统一认证\n\nOAuth2/SSO 接入说明。"}]}'

# deprecate：按 docId 增量废弃（仅该 doc 专属页面被废弃）
curl -sS -X POST "$BASE/api/v1/wiki/wikis/$WID/deprecate-doc" \
  -H 'Content-Type: application/json' -d '{"docId":"doc_merge"}'
```

## 5. 查询：tree / page / search / stat / export

```bash
# 库级页面树（分页）
curl -sS "$BASE/api/v1/wiki/wikis/$WID/tree?page=1&pageSize=20"

# 单页详情（pageId 取自 tree/build 返回）
curl -sS "$BASE/api/v1/wiki/wikis/$WID/page?pageId=wiki_62793b75bb49"

# 检索：关键词 / 中文词 / tag 过滤（--data-urlencode 处理特殊字符）
curl -sS "$BASE/api/v1/wiki/wikis/$WID/search?q=HAProxy&limit=10"
curl -sS --get "$BASE/api/v1/wiki/wikis/$WID/search" --data-urlencode "q=检索"
curl -sS --get "$BASE/api/v1/wiki/wikis/$WID/search" --data-urlencode "tag=方案"

# 统计（pageCount / tag 分布 / linkCount）
curl -sS "$BASE/api/v1/wiki/wikis/$WID/stat"

# 导出 jsonl / json
curl -sS "$BASE/api/v1/wiki/wikis/$WID/export?format=jsonl"
curl -sS "$BASE/api/v1/wiki/wikis/$WID/export?format=json"
```

## 6. 异步任务 jobs（async=1 → Celery 投递 / 手动执行）

```bash
# 提交异步 build（broker 不可达时保持 pending，可手动执行）
JOB_JSON=$(python -c "import json;print(json.dumps({
  'async':'1','docId':'doc_async','title':'异步构建示例',
  'markdown':open('README.md',encoding='utf-8').read()}))")
curl -sS -X POST "$BASE/api/v1/wiki/wikis/$WID/build" -H 'Content-Type: application/json' -d "$JOB_JSON"
# → data.jobId = job_xxxxxxxxxxxx

# 任务列表 / 手动同步执行 / 查询结果
curl -sS "$BASE/api/v1/wiki/jobs?wikiId=$WID"
curl -sS -X POST "$BASE/api/v1/wiki/jobs/job_xxxxxxxxxxxx/run"
curl -sS "$BASE/api/v1/wiki/jobs/job_xxxxxxxxxxxx"   # status: pending/active/success/failed
```

## 7. CLI 等价命令（typer，输出无 envelope，退出码 0/1/6）

```bash
export OPENWIKI_SERVER_DATA_DIR=/tmp/ow-live OPENWIKI_SERVER_OPENWIKI=0

openwiki-server create --kb-id kb_cli_demo --name "CLI 演示 Wiki" \
  --config '{"granularity":"heading"}'
openwiki-server list
openwiki-server build wiki_218456d9ebea --doc-id cli_doc1 --title 命令行构建 \
  --tags cli,示例 --markdown $'# 命令行构建\n\n## 用法\n\nopenwiki-server build <wikiId>'
openwiki-server tree wiki_218456d9ebea
openwiki-server search wiki_218456d9ebea --q 用法
openwiki-server page wiki_218456d9ebea --page-id wiki_2a87433483c9
openwiki-server stat wiki_218456d9ebea
openwiki-server export wiki_218456d9ebea --format json
openwiki-server merge wiki_218456d9ebea --pages '[{"title":"页面A","markdown":"正文"}]'
openwiki-server deprecate-doc wiki_218456d9ebea cli_doc1
openwiki-server job-list --wiki-id wiki_218456d9ebea
openwiki-server job-run job_xxxxxxxxxxxx
openwiki-server delete wiki_218456d9ebea
# 未 pip 安装时可用：PYTHONPATH=. python -c "from openwiki_engine.interfaces.cli import app; app()" <命令>
```

> `update`（全量 LLM 刷新）与 `ingest`（连接器摄取）需要 OpenWiki 内核可用；
> `OPENWIKI_SERVER_OPENWIKI=0` 下调用返回 `200001`（OpenWiki 内核不可用）。

## 8. gRPC（默认 50052，动态 descriptor，方法名同 HTTP 语义）

```bash
python - <<'PY'
from openwiki_engine.interfaces.grpc_server import grpc_client
client = grpc_client("127.0.0.1", 50052)      # 返回 envelope dict
print(client("CreateWiki", {"kbId": "kb_grpc_demo", "name": "gRPC 演示"}))
print(client("Stat", {"wikiId": "wiki_<id>"}))
print(client("Search", {"wikiId": "wiki_<id>", "q": "检索"}))
PY
# 方法全集：CreateWiki/GetWiki/DeleteWiki/ListWikis/BuildWiki/MergeRecords/DeprecateDoc/
#           Tree/Page/Search/Stat/ExportWiki/UpdateWiki/Ingest/RunJob/GetJob
# Docker 栈：gRPC 走 HAProxy TCP 透传（宿主 50052 → 容器 50052）
```

## 9. MCP（stdio JSON-RPC）

```bash
printf '%s\n' \
  '{"jsonrpc":"2.0","id":1,"method":"initialize"}' \
  '{"jsonrpc":"2.0","id":2,"method":"tools/list"}' \
  '{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"wiki_create","arguments":{"kbId":"kb_mcp_demo","name":"MCP 演示"}}}' \
  | openwiki-server serve mcp
# 工具：wiki_create/list/get/delete/tree/page/search/stat/export/
#        build/merge/deprecate_doc/update/ingest/job_run/job_get
```

## 10. 一键演练脚本

`scripts/wiki_api_drill.sh`：起服务（18021，隔离数据目录）→ 探针 → CRUD →
两份真实文档 build → tree/page/search/stat/export → merge/deprecate → 异步 job →
删除 → CLI 等价命令，全部断言通过后打印 `ALL PASS`。

```bash
bash scripts/wiki_api_drill.sh
```
