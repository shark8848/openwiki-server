## 1. 被测对象与变更

### 1.1 本次修复（commit `fdc0476`）

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| openwiki 写入位置嵌套 | `Settings.data_dir` 默认相对路径 `data`，openwiki（Node）按 `os.homedir()` 相对解析，实际写入 `wiki_root/data/wikis/<id>/.openwiki/wiki/`，引擎读 `wiki_root/.openwiki/wiki/` 为空，build 静默降级 `mode: rule` | `config.py` 新增 `resolved_data_dir`（绝对路径），`resolved_db_path`/`wiki_root` 改用它；`sqlite_store.wiki_root()` 返回绝对路径；adapter `run_update`/`run_ingest` 入口 `abspath` 兜底 |
| datetime 响应 500 | OKF front matter 的 YAML 日期（`datetime`/`date`）无法被 FastAPI 默认 JSON 序列化 | adapter `_json_safe()` 归一化字段；`http_app._JsonResponse` 兜底序列化全部响应 |

- 版本提升（commit `4e96111`）：0.3.3 已于 09-01 发布且不含上述修复，故升 `0.3.4` 重新发布 PyPI。
